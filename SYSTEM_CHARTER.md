# The Distance and PIR Sensor
It sees:       how near you are, in cm
It calls you:  near, present, still
It does:       says "Near" or "Far", changes from black to white, 
For them:      changes color
To them:       turns off when nobody is present
It refuses:    to count your visits
Set aside:     Leo's Waiter: no stand by 11/18
Sits next to:  Hansel and Gretel, and pushes back
The tension:   if you move too far back it stops seeing you
